계정 삭제 안내

개발자: milcho0604  |  앱: MealPlan (com.mealplanning.app)

MealPlan은 언제든지 계정과 관련 데이터를 삭제할 수 있는 방법을 제공합니다. 아래 안내에 따라 앱 내에서 직접 삭제하거나, 이메일로 요청하실 수 있습니다.

방법 1 — 앱 내에서 직접 삭제 (즉시 처리)

  1. MealPlan 앱을 실행합니다.
  2. 하단 탭에서 설정을 선택합니다.
  3. 화면 하단의 "회원 탈퇴" 버튼을 누릅니다.
  4. 안내 메시지를 확인한 뒤 탈퇴를 선택합니다.
탈퇴 후 계정은 90일간 비활성화 상태로 유지되며, 그 안에 재로그인하면 복구됩니다. 90일이 지나면 모든 데이터가 영구 삭제됩니다.

방법 2 — 이메일 삭제 요청

앱에 접근하기 어려운 경우 아래 이메일로 요청해 주세요. 영업일 기준 3일 이내 처리됩니다.

이메일: hello.mealplan@gmail.com
제목: [계정 삭제 요청] 가입 이메일 주소
내용: 삭제를 원하는 계정의 이메일 주소를 포함해 주세요.
